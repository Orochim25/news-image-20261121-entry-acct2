**The World in One Day — Saturday 21 November 2026.** A flat-vector broadsheet
summing up the day's world news in one image: 33 stories across 7 regions,
led by COP31 running into overtime as its draft drops fossil fuels, three
Houthi missiles intercepted over Riyadh, and the Wall Street AI sell-off.

- `entry.png` — the 1024×1024 image (drawn by `compose_acct2.py`, PIL)
- `main.py` — standard-library-only program that copies `entry.png` to
  `$MAKEFUN_OUTPUT_DIR/entry.png`
- `compose_acct2.py` — the drawing program (fresh authoring for account 2)

All 33 stories are verified against primary sources dated 21 November 2026;
the DATE CHECK bar names the 20/19 November stories that were excluded.
